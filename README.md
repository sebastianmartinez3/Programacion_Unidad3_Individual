# Actividad Unidad 3. Introducción a la programación orientada a objetos
## Ejercicios
Utilizando el IDE que más te guste para desarrollar con el lenguaje de programación C#, realiza las siguientes tareas:
1.	Define una clase llamada Usuario, que debe tener los siguientes elementos:
-	Atributos:
    -	Identificador
    -	Nombre
    -	Apellidos
    -	Email
    -	Dirección
    -	Población
    -	Debes añadir dos atributos de tu elección
-	Métodos
    -	Constructor que inicialice los atributos
    -	Método que visualice todos los atributos de la clase
2.	Define otra clase llamada Libro, que debe tener los siguientes elementos:
-	Atributos:
    -	Identificador
    -	Título del libro
    -	ISBN
    -	Debe añadir dos atributos de tu elección
-	Métodos
    - Método constructor que inicialice los atributos
    -	Método que visualice todos los atributos de la clase
3.	Se tiene que registrar un usuario y un libro, mediante la consola de entrada, además de poder consultar los datos del usuario y del libro.
## Actividad
Para realizar la actividad se tiene que clonar el repositorio https://github.com/sebastianmartinez3/Programacion_Unidad3_Individual.git. La tarea es individual y el código fuente tiene una clase estática, con 4 métodos estáticos, con el nombre RegitrarUsuario, ConsultarUsuario, RegistrarLibro y ConsultarLibro. donde se tiene que escribir las acciones del menú.
En el código fuente vais a encontrar un menú principal, donde se puede solicitar varias opciones que llama a cada una de la acción correspondiente.
**Todos los datos de la clase se han de pedir por consola para inicializar las dos clases.** He dejado una pista, en el código fuente para la realización de la actividad, para guardar las instancias de las clases.
Se tiene que coger los tipos de datos adecuados para cada una de los atributos o propiedades, solo se puede utilizar todo lo visto hasta ahora en las unidades.
## Entrega
Recuerdo que tenéis que borrar las carpetas /obj y /bin de la carpeta del proyecto y se tiene que subir al aula virtual **un archivo ZIP con el nombre completo del alumno ([NOMBRE_APELLIDOS].zip)** con todo el contenido de vuestro proyecto. **El programa tiene que compilar sin errores y funcionar correctamente.** Si no funciona enviar lo que tengáis, para obtener puntuación.
